<p class="data-vintage">Action date is the date the agency took the rating action. The dataset holds each agency's current published history, so the publicly knowable date is the current file's date and is an upper bound on when the action first became public in this form: earlier editions of the file carried older actions sooner. Actions labeled "No action code in source" are records the agency's file carries without a rating action code, principally affirmations and outlook or watch updates; the rating shown is the rating recorded with the record.
