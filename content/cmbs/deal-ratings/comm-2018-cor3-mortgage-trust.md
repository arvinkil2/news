<p class="data-vintage">Action date is the date the agency took the rating action. Publicly knowable is the publication date of the agency's rating history file, published under SEC Rule 17g-7(b), in which the action is recorded in this dataset. The dataset holds each agency's current published history, so the publicly knowable date is the current file's date and is an upper bound on when the action first became public in this form: earlier editions of the file carried older actions sooner. Actions labeled "No action code in source" are records the agency's file carries without a rating action code, principally affirmations and outlook or watch updates; the rating shown is the rating recorded with the record.
