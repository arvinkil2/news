Microsoft and Intel announced on November 18 an expanded long-term agreement covering Azure infrastructure, under which Microsoft becomes the first company to announce use of Intel Foundry's EMIB advanced packaging technology for Azure first-party silicon. EMIB, the Embedded Multi-die Interconnect Bridge, connects separate dies inside a package and is Intel Foundry's flagship answer to the advanced packaging work that has concentrated at TSMC.

The agreement also confirms multi-year Intel Xeon supply capacity for Azure, including instances of the next-generation server CPUs codenamed Diamond Rapids, and expands collaboration across the Azure roadmap and Intel-based Azure hardware systems. Wedbush Securities, cited in trade coverage of the announcement, said the deal's financial impact for Intel remains uncertain, which is the right caution: no volumes, values or delivery dates were disclosed.

The companies also detailed memory and security work already shipping. Azure M-series v4 virtual machines using CXL memory and Intel Flat Memory Mode on Xeon 6 processors deliver up to 2.3 times greater performance and memory flexibility for demanding workloads, and Intel QuickAssist enabled virtual machines, described as the first in the cloud, run SQL backups up to 2.5 times faster. Confidential virtual machines use Intel Trust Domain Extensions to encrypt memory and CPU register state as they move between hosts.

For Intel, the value of the announcement is less the Xeon supply, which continues an existing relationship, than a hyperscaler publicly attaching its own custom silicon to Intel packaging. Advanced packaging is where AI accelerators are assembled, and a first named customer gives Intel Foundry a reference it can sell against.
