# Sources to implement: official bodies as direct sources

Standing rule (Arvin, 2026-10-26): when a story's substance is an official
release from a body this operation does not cover directly, log the body
here so it gets implemented as a direct source, instead of quoting wires
secondhand again. Where a body IS covered directly, its own release is the
source under the primary-source default; wires are for reaction only.

Catalyst-watch and morning-briefs runs append newly encountered uncovered
bodies to the "Logged, not implemented" table (name, what it publishes,
release-listing URL, date logged, blocker). Do not duplicate entries.
Implementation lands in the scraper lane (feeds/scrapers.py) or the poller
feeds (feeds/master-feeds.yaml); when an entry is implemented, move it to
the implemented table with the route and date.
